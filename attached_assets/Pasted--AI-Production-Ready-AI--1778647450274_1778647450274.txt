한국 주식 고래 추적 및 AI 세력 분석 통합 웹앱 (Production Ready)

아래 요구사항을 엄격하게 준수하여 실제 배포 가능한 수준의 한국 주식 고래 추적 및 AI 세력 분석 웹앱을 완성하라.

절대로 placeholder 코드나 mock 응답으로 구현하지 말 것.
모든 API는 실제 동작 가능한 production-ready 코드로 작성할 것.
파일 생략 금지.
모든 import 포함.
requirements.txt 반드시 생성.
모든 예외처리 포함.
모든 timeout 포함.
모든 async/sync 충돌 방지.
모든 종목코드는 반드시 문자열(str) 6자리로 처리할 것.

[매우 중요] 필수 안정성 규칙
1. 종목코드 처리 규칙 (절대 중요)

모든 종목코드는 반드시 문자열(str) 6자리 유지.

절대 int 변환 금지.

반드시 아래 패턴 사용:

ticker = str(ticker).zfill(6)

pandas merge / dataframe 처리 시에도 반드시:

.astype(str).str.zfill(6)

강제 적용.

예:

"005930" 유지
"5930" 절대 금지
2. pykrx 비동기 블로킹 방지

pykrx는 동기(sync) 라이브러리다.

FastAPI async endpoint 내부에서 직접 호출 금지.

반드시 아래 방식 사용:

await asyncio.to_thread(...)

또는:

from starlette.concurrency import run_in_threadpool

사용.

이벤트 루프 블로킹 절대 금지.

3. FastAPI 안정성 규칙

반드시 포함:

CORSMiddleware 전체 허용
모든 외부 API timeout
모든 API try-except
SSE 연결 종료 처리
websocket reconnect 처리
startup/shutdown lifecycle 처리
4. Anthropic JSON 응답 안정화

Claude 응답은 markdown code block 제거 후 JSON parse 할 것.

예:

response_text = response_text.strip()

if response_text.startswith("```"):
    response_text = response_text.split("\n", 1)[1]
    response_text = response_text.rsplit("```", 1)[0]

JSONDecodeError 발생 시 fallback 처리 필수.

corpCode.xml은 ZIP 압축 응답이다.

반드시:

zipfile 사용
XML 파싱

구현.
